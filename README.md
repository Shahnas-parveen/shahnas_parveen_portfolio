## Getting Started

### Prerequisites

* Node.js 18 or later
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Shahnas-parveen/shahnas-portfolio.git
```

Navigate to the project directory:

```bash
cd shahnas-portfolio
```

Install the dependencies:

```bash
npm install
```

### Run Locally

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

### Production Build

Create a production build:

```bash
npm run build
```

The generated production files will be available in the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```

## Deployment

The portfolio is a Vite-based static website and can be deployed using platforms such as Netlify or Vercel.

### Netlify

* **Build command:** `npm run build`
* **Publish directory:** `dist`
